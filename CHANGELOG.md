## 1.0.4

Hide Names with Interface now also hides the interaction icon with its name and more name displays, Interface Fading can show an element while the mouse is over it, and all chat tabs fade. The menu of the Aklime Mod Tools button opens in the middle of the screen when the button sits in a minimap button collector. / Namen mit Interface ausblenden blendet jetzt auch das Interaktionssymbol mit seinem Namen und weitere Namensanzeigen aus, die Interface Ausblendung kann ein Element einblenden, solange die Maus darüber ist, und alle Chat-Tabs blenden aus. Das Menü des Aklime Mod Tools-Buttons öffnet sich in der Mitte des Bildschirms, wenn der Button in einem Minimap-Button-Sammler sitzt.

**EN**

Interface

* Fixed: Hide Names with Interface left some names visible: the interaction icon with its name above NPCs, the nameplates of friendly players and NPCs, titles, guild lines and your own last name. They are hidden now too.
* New: If the game refuses a setting or something switches it on again while the interface is hidden, a line in the chat says which one when the interface returns.
* New: Show on Mouse Hover. A new option at the top of every mode in Interface Fading. If it is on and you point the mouse at a faded element, for example the action bars, the quest tracker, the buffs or the chat, that element is shown. The rest stays faded. You find it under Interface, Interface Fading.
* New: Battle.net whispers show the chat for a moment, like normal whispers.
* Changed: The chat stays visible as long as the chat input is open, even if you do not type anything.
* Changed: The time under Chat Visible For now also counts after you close the chat input and after the mouse left the chat. The chat stays visible for that time.
* Fixed: The chat could fade out before the time under Chat Visible For was over, for example when the mouse moved over another element. The chat now stays visible for the full time.
* Fixed: Chat tabs that were not shown while the interface faded, for example the tab of a Battle.net conversation or any other whisper tab, stayed visible. All chat tabs fade now.
* Fixed: The minimap moved to the right when you pressed the key that hides the whole interface (Alt+Z by default) while the interface was faded. Interface Fading now leaves everything alone while the interface is hidden.
* Fixed: The objective tracker on the right stayed bright after you hid the whole interface with that key and showed it again while Interface Fading was active. It now stays faded.

Minimap

* Changed: If the Aklime Mod Tools button sits in a minimap button collector, its menu now opens as a row in the middle of the screen, a little larger, from left to right. You pick what you need. This works with our own collector and with the collectors of other addons and needs no setting. A click anywhere outside of the row closes it. Before, the menu hung below the button, where a bar could cover it, or stayed on the curved arc around the minimap.
* Fixed: In the collector of another addon the button can no longer be dragged out of the bar.

**DE**

Interface

* Behoben: Namen mit Interface ausblenden ließ einiges sichtbar: das Interaktionssymbol mit seinem Namen über NPCs, die Namensplaketten freundlicher Spieler und NPCs, Titel, Gildenzeilen und deinen eigenen Nachnamen. Das wird jetzt auch ausgeblendet.
* Neu: Lehnt das Spiel eine Einstellung ab oder schaltet etwas sie wieder ein, während das Interface ausgeblendet ist, steht beim Einblenden eine Zeile im Chat, welche es war.
* Neu: Beim Hovern einblenden. Eine neue Option ganz oben in jedem Modus der Interface Ausblendung. Ist sie an und du fährst mit der Maus über ein ausgeblendetes Element, zum Beispiel die Aktionsleisten, die Questverfolgung, die Buffs oder den Chat, wird dieses Element eingeblendet. Der Rest bleibt ausgeblendet. Du findest sie unter Interface, Interface Ausblendung.
* Neu: Battle.net-Flüstern blenden den Chat kurz ein, wie normales Flüstern.
* Geändert: Der Chat bleibt sichtbar, solange die Chat-Eingabe offen ist, auch wenn du nichts tippst.
* Geändert: Die Zeit unter Chat eingeblendet für gilt jetzt auch, nachdem du die Chat-Eingabe geschlossen hast und nachdem die Maus den Chat verlassen hat. Der Chat bleibt für diese Zeit sichtbar.
* Behoben: Der Chat konnte ausblenden, bevor die Zeit unter Chat eingeblendet für abgelaufen war, zum Beispiel wenn die Maus über ein anderes Element fuhr. Der Chat bleibt jetzt für die volle Zeit sichtbar.
* Behoben: Chat-Tabs, die beim Ausblenden des Interface nicht angezeigt wurden, zum Beispiel der Tab einer Battle.net-Unterhaltung oder ein anderer Flüster-Tab, blieben sichtbar. Alle Chat-Tabs blenden jetzt aus.
* Behoben: Die Minimap rutschte nach rechts, wenn du die Taste zum Ausblenden der gesamten Benutzeroberfläche (standardmäßig Alt+Z) gedrückt hast, während das Interface ausgeblendet war. Die Interface Ausblendung lässt jetzt alles in Ruhe, solange die Benutzeroberfläche versteckt ist.
* Behoben: Die Questverfolgung rechts blieb hell, nachdem du die gesamte Benutzeroberfläche mit dieser Taste versteckt und wieder gezeigt hast, während die Interface Ausblendung aktiv war. Sie bleibt jetzt ausgeblendet.

Minimap

* Geändert: Sitzt der Aklime Mod Tools-Button in einem Minimap-Button-Sammler, öffnet sich sein Menü jetzt als Reihe in der Mitte des Bildschirms, etwas größer, von links nach rechts. Du suchst dir aus, was du brauchst. Das funktioniert mit unserem eigenen Sammler und mit den Sammlern anderer Addons und braucht keine Einstellung. Ein Klick irgendwo außerhalb der Reihe schließt sie. Vorher hing das Menü unter dem Button, wo es von einer Leiste verdeckt werden konnte, oder blieb auf dem Bogen um die Minimap.
* Behoben: Im Sammler eines anderen Addons lässt sich der Button nicht mehr aus der Leiste ziehen.

## 1.0.3

The height of the Character Tracker window can now be set, names can be hidden together with the interface, the threat display and the map navigation can be switched on, and graphics settings can be changed. / Die Höhe des Charakter-Trackers lässt sich jetzt einstellen, Namen lassen sich zusammen mit dem Interface ausblenden, die Bedrohungsanzeige und die Kartennavigation lassen sich einschalten, und Grafik-Einstellungen lassen sich ändern.

**EN**

Character Tracker

* New: A lock to the left of the Characters button unlocks the window. Then the corner at the bottom right can be dragged to set the height of the window. The height is saved.
* New: Free space below the table is filled with striped rows.
* Changed: A new character is added to the Character Tracker right at login. Before, it only appeared after a short delay, so a quick logout could skip it.

Interface

* New: Hide Names with Interface. If you hide the interface with Alt+Z, the names of all players and NPCs and the nameplates are hidden too. When the interface returns, everything is shown as before. You find it under Interface, Interface Fading.
* New: Enable Threat Display. Switches the numeric threat display on the target frame on and off, like the console command threatShowNumeric. You find it under Interface, Character and Portrait.

Minimap

* Changed: If the Aklime Mod Tools button sits in the Minimap Button Collector, its menu now opens as a column below the button in the opened bar. Before, it appeared at the old position at the minimap.
* Fixed: The menu of the Aklime Mod Tools button opens next to the button on the minimap again. Before, it could appear at another place after the button was dragged while it sat in the collector bar. In the bar the button can no longer be dragged.

Quality of Life

* New: Enable Map Navigation. Switches the in-game navigation of the map on and off, like the console command showInGameNavigation. You find it under Quality of Life, Miscellaneous.

Graphics

* New: Graphics Settings. A new category Graphics sets many graphics options of WoW Forever, hidden ones too, like indirect lighting, fog, grass, weather, object detail, camera zoom and sharpening. The options stay grey until you tick the switch at the top. Your own graphics settings are saved at the first login. Turning the feature off brings them back, and the button Default loads them into all options.
* New: Presets Performance, Balanced, Maximum, Classic Look, Modern Look and Blizzard Default. Presets are locked. The button Copy to Custom turns the selected preset into your own set, which has its own saved values and is never changed by a preset.
* New: A movable FPS display, an FPS comparison after every change and a benchmark of 10 seconds per preset.
* New: Loot Sparkles like in the original game, Show Nearest Object and Protect Values, which sets your values again after changes in the game's graphics menu.
* New: A short description under every option explains what it does and why it is there.

**DE**

Charakter-Tracker

* Neu: Ein Schloss links vom Charaktere-Knopf entsperrt das Fenster. Dann lässt sich die Ecke unten rechts ziehen, um die Höhe des Fensters einzustellen. Die Höhe wird gespeichert.
* Neu: Freier Platz unter der Tabelle wird mit Streifenzeilen gefüllt.
* Geändert: Ein neuer Charakter kommt direkt beim Einloggen in den Charakter-Tracker. Vorher erschien er erst nach einer kurzen Verzögerung, ein schnelles Ausloggen konnte ihn also überspringen.

Interface

* Neu: Namen mit Interface ausblenden. Blendest du das Interface mit Alt+Z aus, verschwinden auch die Namen aller Spieler und NPCs sowie die Namensplaketten. Kommt das Interface zurück, wird alles wieder angezeigt wie vorher. Du findest es unter Interface, Interface Ausblendung.
* Neu: Bedrohungsanzeige aktivieren. Schaltet die Bedrohungsanzeige als Zahl am Zielrahmen ein und aus, wie der Konsolenbefehl threatShowNumeric. Du findest sie unter Interface, Charakter und Portrait.

Minimap

* Geändert: Sitzt der Aklime Mod Tools-Button im Minimap Button Sammler, öffnet sich sein Menü jetzt als Spalte unter dem Button in der aufgeklappten Leiste. Vorher erschien es an der alten Stelle an der Minimap.
* Behoben: Das Menü des Aklime Mod Tools-Buttons öffnet sich wieder neben dem Button an der Minimap. Vorher konnte es an einer anderen Stelle erscheinen, wenn der Button in der Sammler-Leiste gezogen wurde. In der Leiste lässt sich der Button nicht mehr ziehen.

Quality of Life

* Neu: Kartennavigation aktivieren. Schaltet die Navigation der Karte im Spiel ein und aus, wie der Konsolenbefehl showInGameNavigation. Du findest sie unter Quality of Life, Sonstiges.

Grafik

* Neu: Grafik-Einstellungen. Eine neue Kategorie Grafik stellt viele Grafik-Optionen von WoW Forever ein, auch versteckte, zum Beispiel indirekte Beleuchtung, Nebel, Gras, Wetter, Objektdetails, Kameradistanz und Schärfe. Die Optionen bleiben ausgegraut, bis du den Schalter oben anhakst. Deine eigenen Grafik-Einstellungen werden beim ersten Login gesichert. Ausschalten bringt sie zurück, und der Knopf Standard lädt sie in alle Optionen.
* Neu: Voreinstellungen Leistung, Ausgewogen, Maximum, Klassischer Look, Moderner Look und Blizzard-Standard. Voreinstellungen sind gesperrt. Der Knopf In Benutzerdefiniert übernehmen macht die gewählte zu deinem eigenen Satz, der eigene gespeicherte Werte hat und nie von einer Voreinstellung verändert wird.
* Neu: Eine verschiebbare FPS-Anzeige, ein FPS-Vergleich nach jeder Änderung und ein Benchmark von 10 Sekunden pro Voreinstellung.
* Neu: Loot-Glitzern wie im Originalspiel, Nächstes Objekt anzeigen und Werte schützen, das deine Werte nach Änderungen im Grafikmenü des Spiels erneut setzt.
* Neu: Eine kurze Beschreibung unter jeder Option erklärt, was sie tut und wozu sie da ist.

The Address Book now works with first and last names and shows the faction. The Character Tracker tooltip shows the last name. / Das Adressbuch arbeitet jetzt mit Vor- und Nachnamen und zeigt die Fraktion. Der Tooltip im Charakter-Tracker zeigt den Nachnamen.

**EN**

Address Book

* Changed: The Address Book now uses first name and last name instead of name and realm, because Forever has only one realm. Both are shown in their own columns, each in the class color.
* Changed: A click on a contact writes the full name with a space into the recipient field.
* New: A third column shows the faction logo (Horde or Alliance).
* Changed: Old contacts are removed once. Every character is added again on its next login.

Character Tracker

* New: The tooltip of a character shows the last name too.
* Fixed: The tooltip showed "St." for the level. It is now written out as "Level".

**DE**

Adressbuch

* Geändert: Das Adressbuch nutzt jetzt Vorname und Nachname statt Name und Realm, weil es in Forever nur einen Realm gibt. Beide stehen in eigenen Spalten, jeweils in Klassenfarbe.
* Geändert: Ein Klick auf einen Kontakt schreibt den vollen Namen mit Leerzeichen ins Empfängerfeld.
* Neu: Eine dritte Spalte zeigt das Fraktionslogo (Horde oder Allianz).
* Geändert: Alte Kontakte werden einmalig entfernt. Jeder Charakter wird bei seinem nächsten Login neu hinzugefügt.

Charakter-Tracker

* Neu: Der Tooltip eines Charakters zeigt jetzt auch den Nachnamen.
* Behoben: Der Tooltip zeigte "St." für die Stufe. Sie wird jetzt ausgeschrieben als "Stufe".
