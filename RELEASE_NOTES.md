## 1.0.4

**EN**

Interface

* Fixed: Hide Names with Interface left some names visible: the interaction icon with its name above NPCs, the nameplates of friendly players and NPCs, titles, guild lines and your own last name. They are hidden now too.
* New: If the game refuses a setting or something switches it on again while the interface is hidden, a line in the chat says which one when the interface returns.
* New: Show on Mouse Hover. A new option at the top of every mode in Interface Fading. If it is on and you point the mouse at a faded element, for example the action bars, the quest tracker, the buffs or the chat, that element is shown. The rest stays faded. You find it under Interface, Interface Fading.
* New: Battle.net whispers show the chat for a moment, like normal whispers.
* Changed: The chat stays visible as long as the chat input is open, even if you do not type anything.
* Changed: The time under Chat Visible For now also counts after you close the chat input and after the mouse left the chat. The chat stays visible for that time.
* Fixed: The chat could fade out before the time under Chat Visible For was over, for example when the mouse moved over another element. The chat now stays visible for the full time.
* Fixed: Chat tabs that were not shown while the interface faded, for example the tab of a Battle.net conversation or any other whisper tab, stayed visible. All chat tabs fade now.
* Fixed: The minimap moved to the right when you pressed the key that hides the whole interface (Alt+Z by default) while the interface was faded. Interface Fading now leaves everything alone while the interface is hidden.
* Fixed: The objective tracker on the right stayed bright after you hid the whole interface with that key and showed it again while Interface Fading was active. It now stays faded.

Minimap

* Changed: If the Aklime Mod Tools button sits in a minimap button collector, its menu now opens as a row in the middle of the screen, a little larger, from left to right. You pick what you need. This works with our own collector and with the collectors of other addons and needs no setting. A click anywhere outside of the row closes it. Before, the menu hung below the button, where a bar could cover it, or stayed on the curved arc around the minimap.
* Fixed: In the collector of another addon the button can no longer be dragged out of the bar.

**DE**

Interface

* Behoben: Namen mit Interface ausblenden ließ einiges sichtbar: das Interaktionssymbol mit seinem Namen über NPCs, die Namensplaketten freundlicher Spieler und NPCs, Titel, Gildenzeilen und deinen eigenen Nachnamen. Das wird jetzt auch ausgeblendet.
* Neu: Lehnt das Spiel eine Einstellung ab oder schaltet etwas sie wieder ein, während das Interface ausgeblendet ist, steht beim Einblenden eine Zeile im Chat, welche es war.
* Neu: Beim Hovern einblenden. Eine neue Option ganz oben in jedem Modus der Interface Ausblendung. Ist sie an und du fährst mit der Maus über ein ausgeblendetes Element, zum Beispiel die Aktionsleisten, die Questverfolgung, die Buffs oder den Chat, wird dieses Element eingeblendet. Der Rest bleibt ausgeblendet. Du findest sie unter Interface, Interface Ausblendung.
* Neu: Battle.net-Flüstern blenden den Chat kurz ein, wie normales Flüstern.
* Geändert: Der Chat bleibt sichtbar, solange die Chat-Eingabe offen ist, auch wenn du nichts tippst.
* Geändert: Die Zeit unter Chat eingeblendet für gilt jetzt auch, nachdem du die Chat-Eingabe geschlossen hast und nachdem die Maus den Chat verlassen hat. Der Chat bleibt für diese Zeit sichtbar.
* Behoben: Der Chat konnte ausblenden, bevor die Zeit unter Chat eingeblendet für abgelaufen war, zum Beispiel wenn die Maus über ein anderes Element fuhr. Der Chat bleibt jetzt für die volle Zeit sichtbar.
* Behoben: Chat-Tabs, die beim Ausblenden des Interface nicht angezeigt wurden, zum Beispiel der Tab einer Battle.net-Unterhaltung oder ein anderer Flüster-Tab, blieben sichtbar. Alle Chat-Tabs blenden jetzt aus.
* Behoben: Die Minimap rutschte nach rechts, wenn du die Taste zum Ausblenden der gesamten Benutzeroberfläche (standardmäßig Alt+Z) gedrückt hast, während das Interface ausgeblendet war. Die Interface Ausblendung lässt jetzt alles in Ruhe, solange die Benutzeroberfläche versteckt ist.
* Behoben: Die Questverfolgung rechts blieb hell, nachdem du die gesamte Benutzeroberfläche mit dieser Taste versteckt und wieder gezeigt hast, während die Interface Ausblendung aktiv war. Sie bleibt jetzt ausgeblendet.

Minimap

* Geändert: Sitzt der Aklime Mod Tools-Button in einem Minimap-Button-Sammler, öffnet sich sein Menü jetzt als Reihe in der Mitte des Bildschirms, etwas größer, von links nach rechts. Du suchst dir aus, was du brauchst. Das funktioniert mit unserem eigenen Sammler und mit den Sammlern anderer Addons und braucht keine Einstellung. Ein Klick irgendwo außerhalb der Reihe schließt sie. Vorher hing das Menü unter dem Button, wo es von einer Leiste verdeckt werden konnte, oder blieb auf dem Bogen um die Minimap.
* Behoben: Im Sammler eines anderen Addons lässt sich der Button nicht mehr aus der Leiste ziehen.
